# Messages (`frontend/src/messages`)

ข้อความทั้งหมดของหน้าเว็บ แยกตามภาษา โหลดผ่าน `next-intl`

| ไฟล์ | ภาษา |
|---|---|
| `th.json` | ไทย (ค่าเริ่มต้น) |
| `en.json` | อังกฤษ |

กติกา

- สองไฟล์ต้องมีคีย์ชุดเดียวกัน (ตอนนี้ 517 คีย์) เพิ่มหรือลบต้องทำทั้งสองไฟล์
- คีย์บางกลุ่มถูกประกอบตอนรัน จากคำนำหน้า `sat_short_`, `cal_state_`, `fr_flag_`, `fr_reason_`, `help_alert_`, `rt_reason_`, `lc_` จึงค้นชื่อเต็มในโค้ดไม่เจอ
- ถ้าเพิ่มสถานะใหม่ของฝั่งดาวเทียม ต้องเพิ่มข้อความ `sat_<สถานะ>` และ `sat_short_<สถานะ>`
