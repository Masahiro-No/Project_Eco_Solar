# Lib (`frontend/src/lib`)

| ไฟล์ | เนื้อหา |
|---|---|
| `config.ts` | ที่อยู่ของ API (`NEXT_PUBLIC_API_URL` ค่าเริ่มต้น `http://localhost:8000`) |
| `levels.ts` | สี ไอคอน และข้อความของระดับการเตือนและระดับผลกระทบของเมฆ เกณฑ์แสงลด 10% และ 30% และรายการสถานะของฝั่งดาวเทียม |
| `time.ts` | แปลงเวลาที่ backend ส่งมา (UTC) และสร้างป้ายเวลาของแต่ละก้าวพยากรณ์เป็นเวลาไทย |

เกณฑ์ใน `levels.ts` ต้องตรงกับ `service/workers/cloud_coverage.py` และรายการสถานะต้องตรงกับที่ worker ส่งมา
