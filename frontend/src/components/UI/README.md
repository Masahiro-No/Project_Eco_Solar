# UI Components (`frontend/src/components/UI`)

ชิ้นส่วนที่หน้าต่าง ๆ ใช้ ทุกชิ้นอ่านข้อมูลจริงผ่าน context หรือ API สีใช้ตัวแปรของธีมใน `app/globals.css`

**โครงและเมนู**

| ไฟล์ | หน้าที่ |
|---|---|
| `TopBar.tsx` | แถบบน: เลือกสถานี เป้ากำลังผลิต ภาษา ปุ่มสลับธีม เมนูผู้ใช้ |
| `Sidebar.tsx` | เมนู 4 กลุ่ม (ติดตาม ข้อมูล ดูแลโมเดล ช่วยเหลือ) กลุ่มดูแลโมเดลเห็นเฉพาะ admin |
| `Panel.tsx` | กรอบการ์ดที่มีหัวเรื่อง |
| `InfoTip.tsx` | ปุ่มคำอธิบายสั้นข้างหัวข้อ |

**หน้าแรก**

| ไฟล์ | หน้าที่ |
|---|---|
| `StatusHero.tsx` | การ์ดสถานะตอนนี้และคำแนะนำ ถ้าผลพยากรณ์เก่าเกิน 25 นาทีจะขึ้นว่ารอผลรอบใหม่ (ใช้ที่ `/decision` ด้วย) |
| `KpiRow.tsx` | ตัวเลขสามตัว: กำลังผลิตที่คาด เป้า และส่วนที่ขาดมากสุด |
| `GhiForecastChart.tsx`, `PowerForecastChart.tsx` | กราฟ GHI และกำลังผลิต 3 ชั่วโมง พร้อมแถบความไม่แน่นอน |
| `CloudPanel.tsx` | สัดส่วนเมฆรอบสถานี ภาพล่าสุด สถานะของฝั่งดาวเทียม และป้ายว่าสูตรแสงเทียบกับเครื่องวัดแล้วหรือยัง |
| `ForecastFreshness.tsx` | ป้ายบอกอายุของผลพยากรณ์ และ `useForecastAge` ที่ชิ้นอื่นใช้ตัดสินว่าผลเก่าเกินไปหรือไม่ |

**หน้าอื่น**

| ไฟล์ | หน้าที่ | ใช้ที่ |
|---|---|---|
| `DayCharts.tsx` | กราฟของทั้งวัน: GHI กำลังผลิต เมฆ | `/forecast` |
| `CloudPlayer.tsx` | ตัวเล่นภาพเมฆ ภาพจริงต่อด้วยภาพที่ทำนาย | `/forecast` |
| `DecisionSupport.tsx` | ระดับการเตือน คำแนะนำ และตารางตัดสิน | `/decision` |
| `StationTable.tsx` | ตารางของทุกสถานีพร้อมผลพยากรณ์ล่าสุด | `/alerts` |
| `StationSettings.tsx` | แผงแก้ค่าของสถานี | `/stations` |
| `LocationPicker.tsx` | แผนที่เลือกตำแหน่งสถานี (Leaflet) | `/stations` |
| `LstmStatusPanel.tsx` | รุ่น LSTM ที่ใช้งานและรอบ retrain ล่าสุด | `/labeling` |
| `CalibrationStatusPanel.tsx` | สถานะการตรวจสูตรแสงของสถานี | `/labeling` |
| `LearningCurves.tsx` | กราฟการเรียนรู้ราย epoch | `/retrain` |
