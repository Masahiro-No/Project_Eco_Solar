# Frontend Source (`frontend/src`)

โค้ดของหน้าเว็บ (Next.js 15 แบบ App Router, TypeScript, Tailwind)

| โฟลเดอร์ | เนื้อหา |
|---|---|
| [app](app/) | หน้าเว็บ หนึ่งโฟลเดอร์ต่อหนึ่งเส้นทาง รวมธีมและโครงหน้า |
| [components](components/) | ชิ้นส่วนที่หน้าต่าง ๆ ใช้ร่วมกัน |
| [context](context/) | สถานะที่ใช้ทั้งแอป: การล็อกอิน ผลพยากรณ์ ภาษา ธีม |
| [services](services/) | ฟังก์ชันเรียก API ของ backend |
| [lib](lib/) | ค่าตั้งและฟังก์ชันช่วย (ระดับการเตือน เวลา ที่อยู่ API) |
| [messages](messages/) | ข้อความของหน้าเว็บ ภาษาไทยและอังกฤษ |

ทุกค่าที่แสดงมาจาก API ถ้าไม่มีข้อมูล หน้าจอบอกว่าไม่มี ไม่มีข้อมูลตัวอย่างในโค้ด
