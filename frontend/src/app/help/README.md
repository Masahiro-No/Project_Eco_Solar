# คู่มือและคำย่อ (`/help`)

**ใครเห็น:** ทุกคนที่ล็อกอิน

อธิบายคำย่อและตัวเลขที่ใช้ในระบบ (GHI, P_gen, P_target, ΔP, AOI) ความหมายของระดับการเตือนแต่ละระดับ และวิธีอ่านกราฟ เนื้อหาทั้งหมดอยู่ในไฟล์ข้อความ ไม่เรียก API

| | |
|---|---|
| API ที่เรียก | ไม่มี |
| ชิ้นส่วนหลัก | `messages/th.json`, `messages/en.json` |

ไฟล์เดียวในโฟลเดอร์คือ `page.tsx`
