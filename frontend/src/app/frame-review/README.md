# ตรวจภาพดาวเทียม (`/frame-review`)

**ใครเห็น:** admin

ภาพ B03 ช่วงกลางวันของสถานีและวันที่เลือก ผู้ดูแลทำเครื่องหมายว่าใช้ได้หรือใช้ไม่ได้ ภาพที่ระบบสงสัยมีธงบอก มีปุ่มรับทั้งหมดยกเว้นภาพที่ติดธง ภาพที่ใช้ไม่ได้จะไม่เข้าชุด retrain ของ ConvLSTM และแสดงรุ่น ConvLSTM ที่ใช้งานกับตัวนับภาพของรอบถัดไป

| | |
|---|---|
| API ที่เรียก | `GET`/`POST /api/frame-review/frames`, `GET /api/frame-review/status` |
| ชิ้นส่วนหลัก | `services/frameReviewApi.ts` |

ไฟล์เดียวในโฟลเดอร์คือ `page.tsx`
