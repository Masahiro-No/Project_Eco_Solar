# พยากรณ์ของทั้งวัน (`/forecast`)

**ใครเห็น:** ทุกคนที่ล็อกอิน

กราฟ GHI กำลังผลิต และเมฆของทั้งวันที่เลือก เทียบกับค่าวัดจริงเมื่อมี เลือกระยะล่วงหน้าได้ 10 / 60 / 120 / 180 นาที แสดง MAE ของเส้นรวมและของ LSTM อย่างเดียว ตัวเล่นภาพเมฆ (ภาพจริงของวัน ต่อด้วยภาพที่ ConvLSTM ทำนาย) และตาราง 3 ชั่วโมงข้างหน้า

| | |
|---|---|
| API ที่เรียก | `GET /api/inference/predictions-by-date`, `GET /api/ingestion/satellite/{id}/day-frames` |
| ชิ้นส่วนหลัก | `DayCharts.tsx`, `CloudPlayer.tsx` |

ไฟล์เดียวในโฟลเดอร์คือ `page.tsx`
