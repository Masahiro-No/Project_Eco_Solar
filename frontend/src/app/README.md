# Pages (`frontend/src/app`)

หนึ่งโฟลเดอร์คือหนึ่งเส้นทางของเว็บ ไฟล์ `page.tsx` ในโฟลเดอร์คือหน้านั้น

| เส้นทาง | โฟลเดอร์ | หน้า | ใครเห็น |
|---|---|---|---|
| `/` | (ไฟล์ในโฟลเดอร์นี้) | แดชบอร์ด: สถานะตอนนี้ ตัวเลขหลัก กราฟ 3 ชั่วโมง เมฆรอบสถานี | ทุกคนที่ล็อกอิน |
| `/forecast` | [forecast](forecast/) | พยากรณ์ของทั้งวัน | ทุกคนที่ล็อกอิน |
| `/decision` | [decision](decision/) | สนับสนุนการตัดสินใจ | ทุกคนที่ล็อกอิน |
| `/alerts` | [alerts](alerts/) | การแจ้งเตือน | ทุกคนที่ล็อกอิน |
| `/stations` | [stations](stations/) | สถานีผลิตไฟฟ้า | ทุกคนที่ล็อกอิน (แก้ได้เฉพาะ admin) |
| `/inputs` | [inputs](inputs/) | ข้อมูลป้อนโมเดล | ทุกคนที่ล็อกอิน |
| `/labeling` | [labeling](labeling/) | บันทึกค่าวัดจริง | admin |
| `/frame-review` | [frame-review](frame-review/) | ตรวจภาพดาวเทียม | admin |
| `/retrain` | [retrain](retrain/) | สถานะ retrain | admin |
| `/help` | [help](help/) | คู่มือและคำย่อ | ทุกคนที่ล็อกอิน |
| `/login` | [login](login/) | เข้าสู่ระบบและสมัครบัญชี | ทุกคน |

## ไฟล์ในโฟลเดอร์นี้

- `layout.tsx` โครงของทุกหน้า โหลดฟอนต์ และตั้งธีมก่อนหน้าแสดงเพื่อไม่ให้กะพริบ
- `page.tsx` และ `Dashboard.tsx` หน้าแรก
- `globals.css` สีของธีมสว่างและธีมมืด (ตัวแปร CSS) และสีของกราฟ
- [fonts](fonts/) ไฟล์ฟอนต์, `favicon.ico`

หน้าของ admin ถูกซ่อนจากเมนูของ operator และ API ตรวจ role ซ้ำทุกครั้ง การซ่อนเมนูไม่ใช่ตัวกันสิทธิ์
