# การแจ้งเตือน (`/alerts`)

**ใครเห็น:** ทุกคนที่ล็อกอิน

รายการสถานีที่ผลพยากรณ์ล่าสุดอยู่ในระดับเฝ้าระวัง เตือน หรือวิกฤต พร้อมคำแนะนำและกำลังสำรองที่ควรเตรียม กดเลือกสถานีจากรายการเพื่อดูในหน้าอื่นได้ มีปุ่มโหลดใหม่ และตารางของทุกสถานีพร้อมผลล่าสุดอยู่ด้านล่าง จำนวนรายการคือตัวเลขสีแดงบนเมนู

| | |
|---|---|
| API ที่เรียก | `GET /api/dashboard/alerts` |
| ชิ้นส่วนหลัก | `components/UI/StationTable.tsx` |

ไฟล์เดียวในโฟลเดอร์คือ `page.tsx`
