# ข้อมูลป้อนโมเดล (`/inputs`)

**ใครเห็น:** ทุกคนที่ล็อกอิน

สิ่งที่โมเดลได้รับจริง: กราฟของวันสำหรับ 6 ตัวแปรสภาพอากาศ ค่าล่าสุดของฟีเจอร์ที่ป้อน LSTM พร้อมที่มาของแต่ละค่า และภาพ 12 เฟรมที่ ConvLSTM ใช้ในรอบล่าสุด พร้อมบอกเฟรมที่ขาด

| | |
|---|---|
| API ที่เรียก | `GET /api/ingestion/weather/{id}/recent`, `GET /api/ingestion/satellite/{id}/day-frames` |
| ชิ้นส่วนหลัก | `services/dayViewApi.ts` |

ไฟล์เดียวในโฟลเดอร์คือ `page.tsx`
