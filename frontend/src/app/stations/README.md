# สถานีผลิตไฟฟ้า (`/stations`)

**ใครเห็น:** ทุกคนที่ล็อกอิน ดูได้ แก้ได้เฉพาะ admin

ตารางสถานีพร้อมระดับการเตือนล่าสุด เพิ่มสถานีโดยเลือกตำแหน่งบนแผนที่ กดที่สถานีเพื่อเปิดแผงตั้งค่า (ชื่อ พื้นที่แผง ประสิทธิภาพ เป้ากำลังผลิต) ปิดใช้และเปิดใช้สถานีอีกครั้งได้ ค่าที่แก้มีผลตั้งแต่รอบพยากรณ์ถัดไป

| | |
|---|---|
| API ที่เรียก | `/api/stations` ทุกเส้นทาง |
| ชิ้นส่วนหลัก | `StationSettings.tsx`, `LocationPicker.tsx` (แผนที่ Leaflet) |

ไฟล์เดียวในโฟลเดอร์คือ `page.tsx`
