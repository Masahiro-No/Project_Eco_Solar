# Services (`frontend/src/services`)

ฟังก์ชันเรียก API ของ backend ทุกคำขอแนบ token และเมื่อ API ตอบ 401 จะส่งสัญญาณให้ออกจากระบบ

| ไฟล์ | เรียกอะไร |
|---|---|
| `api.ts` | สถานี ผลพยากรณ์ล่าสุดและย้อนหลัง การแจ้งเตือน ภาพดาวเทียมล่าสุด และชนิดข้อมูลหลัก (`solarApi`, `apiFetch`) |
| `dayViewApi.ts` | มุมมองทั้งวัน ภาพของวัน สภาพอากาศย้อนหลัง สถานะ retrain กราฟการเรียนรู้ สถานะการตรวจสูตรแสง |
| `labelingApi.ts` | บันทึกค่าวัดจริง ดูตัวอย่างและอัปโหลดไฟล์ (`labelingApi`, `send`) |
| `frameReviewApi.ts` | ภาพที่ต้องตรวจ บันทึกผลตรวจ และสถานะ ConvLSTM (`frameReviewApi`) |

ฟังก์ชันคืน `null` หรือรายการว่างเมื่อเรียกไม่สำเร็จ ไม่มีข้อมูลตัวอย่างมาแทน
