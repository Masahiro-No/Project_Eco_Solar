# เอกสารของ SolarDSS (`docs`)

รายละเอียดเชิงลึกที่แยกออกมาจาก [README หลัก](../README.md) README หลักตอบว่าโปรเจกต์นี้คืออะไรและเปิดอย่างไร โฟลเดอร์นี้ตอบว่าทำงานอย่างไร ทำไมเลือกวิธีนี้ และวัดผลได้เท่าไร

| เอกสาร | เนื้อหา |
|---|---|
| [architecture.md](architecture.md) | ทางเดินของข้อมูล บริการแต่ละตัว โซน Public / Private หน้าที่แสดงข้อมูลทั้งวัน |
| [models.md](models.md) | LSTM, ConvLSTM, การวัดภาพในกรอบรอบสถานี, สมการรวมผล, แถบความไม่แน่นอน |
| [calibration.md](calibration.md) | การแปลงความสว่างของภาพเป็นแสง ค่า a, b วิธี fit และการตรวจกับแต่ละสถานี |
| [decision.md](decision.md) | กำลังผลิต เป้าตามแดด ระดับการเตือน และกำลังสำรองที่แนะนำ |
| [missing-data.md](missing-data.md) | กติกาเมื่อภาพดาวเทียมหรือสภาพอากาศขาด |
| [retraining.md](retraining.md) | การ retrain ของทั้งสองโมเดล เกณฑ์รับโมเดลใหม่ MLflow และบทบาทของผู้ดูแล |
| [experiments.md](experiments.md) | ผลการทดลองและเหตุผลของค่าที่เลือก (ความยาวข้อมูลย้อนหลัง, persistence, τ, เฟรมที่ขาด) |
| [testing.md](testing.md) | ชุดทดสอบ การรันโมเดลย้อนหลัง และการลบข้อมูลทดสอบ |
| [limitations.md](limitations.md) | ข้อจำกัดที่รู้ทั้งหมด |
| [course-topics.md](course-topics.md) | หัวข้อของรายวิชา 241-353 ที่ใช้ในระบบ |

แผนงาน ข้อกำหนด และสถานะรายข้ออยู่ใน [PLAN.md](../PLAN.md) คำอธิบายของโค้ดแต่ละโฟลเดอร์อยู่ใน README ของโฟลเดอร์นั้น
