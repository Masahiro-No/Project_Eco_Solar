# Sample Files (`backend/scripts/samples`)

ไฟล์ตัวอย่างค่า GHI ที่วัดจริง ในรูปแบบเดียวกับไฟล์ที่ดาวน์โหลดจากเครื่องวัดของ พพ. ใช้สองทาง

- ให้ `check_ground_truth_flow.py` ตรวจว่าตัวอ่านไฟล์ให้ผลเหมือนกันทั้ง CSV และ XLSX
- เป็นตัวอย่างรูปแบบไฟล์สำหรับอัปโหลดในหน้าบันทึกค่าวัดจริง

| ไฟล์ | เนื้อหา |
|---|---|
| `sample_solar_intensity.csv` | เวลาและความเข้มแสง (W/m²) มีแถวซ้ำและค่าติดลบปนอยู่เพื่อทดสอบกติกา |
| `sample_solar_intensity.xlsx` | ข้อมูลชุดเดียวกันในรูปแบบ Excel |

กติกาของตัวอ่าน (`backend/api/label_studio/file_import.py`): เวลาปัดลงเป็นช่อง 10 นาที เวลาที่ไม่มีเขตเวลาถือเป็นเวลาไทย แถวที่ตกช่องเดียวกันใช้แถวสุดท้าย ค่าติดลบปรับเป็น 0
