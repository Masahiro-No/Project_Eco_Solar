# Frame Review Module (`backend/api/frame_review`)

ให้ผู้ดูแลตรวจภาพดาวเทียมจริงของแต่ละสถานีก่อนใช้ retrain ConvLSTM ภาพที่ถูกทำเครื่องหมายว่าใช้ไม่ได้จะไม่เข้าชุดเทรนรอบถัดไป ทุกเส้นทางต้องเป็น `admin`

| Method | Endpoint | ใช้ทำอะไร |
|---|---|---|
| `GET` | `/api/frame-review/frames?station_id=&date=` | ภาพ B03 ช่วงกลางวันของสถานีและวันที่เลือก พร้อมข้อสังเกตอัตโนมัติและผลตรวจที่บันทึกไว้ |
| `POST` | `/api/frame-review/frames` | บันทึกผลตรวจ (ใช้ได้ / ใช้ไม่ได้ และเหตุผล) |
| `GET` | `/api/frame-review/status` | จำนวนภาพใหม่ที่นับไว้สำหรับรอบ retrain ถัดไป รุ่น ConvLSTM ที่ใช้งาน และผลของรอบล่าสุด |

## ข้อสังเกตอัตโนมัติ

ภาพกลางคืนถูกข้าม ภาพกลางวันที่ดำทั้งภาพ ดำบางส่วน หรือความสว่างกระโดดจากเฟรมก่อนหน้ามาก จะถูกติดธงให้ผู้ดูแลดู ธงเป็นแค่คำแนะนำ คนเป็นผู้ตัดสิน

## ไฟล์

- `service.py` อ่านภาพจาก bucket `satellite-cache` (ไฟล์ `b03_*`) และคิดข้อสังเกต
- `model.py` ตาราง `satellite_frame_reviews` (หนึ่งแถวต่อสถานีและเวลาสแกน)
- `controller.py`, `router.py`, `schema.py`
