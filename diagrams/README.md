# Diagrams (`diagrams`)

แผนภาพรวมของระบบที่ใช้ใน `README.md` หลัก

| ไฟล์ | เนื้อหา |
|---|---|
| `overview.png` | ทางเดินของข้อมูลตั้งแต่ Open-Meteo และ NICT จนถึงหน้าเว็บ และโซน Public / Private |
| `overview.py` | สคริปต์ที่วาดภาพนี้ด้วย matplotlib |

เมื่อระบบเปลี่ยน ให้แก้กล่องใน `overview.py` แล้ววาดใหม่ ไม่แก้ภาพด้วยมือ

```bash
python diagrams/overview.py
```
