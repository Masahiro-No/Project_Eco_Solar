# Workers (`service/workers`)

งานเบื้องหลังที่รันบน ARQ (คิวใน Redis) ลงทะเบียนใน `service/main.py`

**ตัวงาน**

| ไฟล์ | คอนเทนเนอร์ | หน้าที่ |
|---|---|---|
| `ingestion_worker.py` | `ingestion-worker` | ทุก 10 นาที (นาทีที่ 8, 18, …) และหนึ่งรอบทันทีตอนเริ่ม: ดึงภาพดาวเทียมและสภาพอากาศของทุกสถานี เติมช่องที่ขาด สั่งพยากรณ์ เก็บผลทุกนาที และนับภาพใหม่เพื่อเริ่ม retrain ConvLSTM |
| `inference_worker.py` | `inference-worker` | พยากรณ์หนึ่งสถานี: รัน LSTM คิดฝั่งดาวเทียม รวมผล แล้วตัดสินระดับการเตือน |
| `train_worker.py` | `trainer-worker` | รับงาน retrain LSTM, retrain ConvLSTM และตรวจสูตรแสง แล้วเรียกโค้ดใน `service/training/` |

**ส่วนประกอบของการพยากรณ์**

| ไฟล์ | หน้าที่ |
|---|---|
| `satellite_preprocessor.py` | หาภาพจริง 12 เฟรมล่าสุด (จาก cache ใน MinIO หรือ NICT) กติกาเมื่อภาพขาด: ถอยไม่เกิน 30 นาที เว้นรอบที่ขาดหนึ่งรอบ หรือใช้เฉพาะเฟรมล่าสุด และเก็บภาพที่ทำนายไว้ให้หน้าเว็บ |
| `cloud_coverage.py` | สัดส่วนเมฆและความสว่างในกรอบรอบสถานี แปลงเป็นดัชนีฟ้าใสด้วยค่า calibration และระดับผลกระทบ |
| `ghi_blend.py` | รวม GHI ของ LSTM กับของดาวเทียม ด้วยน้ำหนัก `w(t) = 0.9·exp(−t/102)` |
| `decision.py` | กฎชุดเดียวของการตัดสินใจ: เป้าตามแดด ส่วนที่ขาด ระดับการเตือน คำแนะนำ และแถบความไม่แน่นอน |
| `solar_geometry.py` | ตำแหน่งดวงอาทิตย์และ GHI ฟ้าใส (สูตรเดียวกับ `backend/api/ingestion/solar_calculator.py`) |
| `convlstm_batch.py` | นับเวลาสแกนใหม่และหาชุดภาพต่อเนื่องสำหรับ retrain ConvLSTM |
| `round_lock.py` | ให้รอบดึงข้อมูลรันทีละรอบ รอบที่มาซ้อนถูกข้าม |

กติการ่วม: ถ้าข้อมูลส่วนใดขาด worker บันทึกสถานะและเหตุผล ไม่สร้างค่าแทน โมเดลที่โหลดแล้วถูกเก็บในหน่วยความจำจนไฟล์เปลี่ยน ค่าที่ปรับได้อยู่ในตัวแปรของ `compose.yml`
