# Training (`service/training`)

การเทรนและ retrain ของทั้งสองโมเดล และเครื่องมือวัดผล รันใน `trainer-worker`

**Retrain (ระบบเรียกเอง)**

| ไฟล์ | หน้าที่ |
|---|---|
| `retrain_timeseries.py` | fine-tune LSTM จากค่า GHI ที่วัดจริง กันวันล่าสุดไว้ตรวจ รับโมเดลใหม่เมื่อดีขึ้นเทียบค่าวัดจริงและไม่แย่ลงเกิน 5% บนชุดตรวจเดิม |
| `retrain_convlstm.py` | fine-tune ConvLSTM จากภาพจริง รอบละ 50 เวลาสแกน ไม่ใช้ภาพที่ผู้ดูแลปฏิเสธ มีโครงของโมเดลและเกณฑ์รับโมเดลใหม่ |
| `features.py` | สร้างตารางฟีเจอร์บนช่อง 10 นาทีจาก `weather_history` (ต้องให้ผลแบบเดียวกับ `backend/api/inference/weather_grid.py`) |
| `dataset.py` | รายชื่อฟีเจอร์ 16 ตัว หน้าต่างข้อมูล และตัวอ่านชุดข้อมูลจาก MinIO |
| `onnx_weights.py` | โหลดน้ำหนักจากไฟล์ ONNX กลับเข้าโมเดล PyTorch เพื่อเทรนต่อ |
| `curves.py` | บันทึกกราฟการเรียนรู้ราย epoch ลง MLflow |
| `calibrate_satellite_ghi.py` | fit และตรวจสูตรแปลงความสว่างของภาพเป็นดัชนีฟ้าใส กับค่าวัดจริง |

**รันด้วยมือ**

| ไฟล์ | หน้าที่ |
|---|---|
| `train.py` | เทรน LSTM ตั้งต้นจากชุดข้อมูล NSRDB และการทดลองความยาวข้อมูลย้อนหลัง (`--ablation 36 48 72 144`) |
| `backtest_cloud.py` | วัดความแม่นของสัดส่วนเมฆที่ ConvLSTM ทำนาย เทียบกับการคงค่าล่าสุด รายระยะ |

ทุกรอบ retrain บันทึกลง MLflow ว่านำไปใช้หรือถูกปฏิเสธพร้อมเหตุผล โมเดลใหม่ถูกเขียนลง `model/` และ MinIO เมื่อผ่านเกณฑ์เท่านั้น เปิดปิดด้วย `ENABLE_RETRAIN`
