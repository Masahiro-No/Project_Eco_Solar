# Deployed Models (`model`)

ไฟล์โมเดลที่ระบบใช้งานอยู่ worker อ่านจากโฟลเดอร์นี้โดยตรง และเมื่อ retrain ผ่านเกณฑ์ ไฟล์ในนี้จะถูกแทนที่ด้วยรุ่นใหม่ ไฟล์เหล่านี้อยู่ใน git เพื่อให้เครื่องที่ clone ไปพยากรณ์ได้ทันที

| โฟลเดอร์ | โมเดล | ใช้ที่ไหน |
|---|---|---|
| [time-series](time-series/) | LSTM พยากรณ์ GHI 3 ชั่วโมงจากสภาพอากาศ | `inference-worker` |
| [convlstm](convlstm/) | ConvLSTM ทำนายภาพดาวเทียม 18 เฟรมถัดไป | `inference-worker` |
| [satellite](satellite/) | ค่าที่ใช้แปลงความสว่างของภาพเป็นดัชนีฟ้าใส | `inference-worker` และ API |

- โฟลเดอร์ `backups/` ของแต่ละโมเดล (รุ่นก่อนหน้าที่ retrain เก็บไว้) ไม่อยู่ใน git
- worker เก็บโมเดลที่โหลดแล้วไว้ในหน่วยความจำ และโหลดใหม่เมื่อไฟล์เปลี่ยน
- ไม่มีไฟล์สำรอง: ถ้าไฟล์หาย ฝั่งนั้นของการพยากรณ์จะหยุดและบอกเหตุผล
