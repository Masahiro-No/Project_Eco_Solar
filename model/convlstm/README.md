# ConvLSTM (`model/convlstm`)

โมเดลทำนายภาพดาวเทียม รับภาพ Band 03 ของ Himawari รอบสถานี 12 เฟรมล่าสุด (64×64 พิกเซล ห่างกัน 10 นาที) ทำนาย 18 เฟรมถัดไป ระบบเอาความสว่างในกรอบรอบสถานีของภาพที่ทำนายไปคิดแสงที่จะลดลง รุ่นที่อยู่ในโฟลเดอร์ตอนเขียนเอกสารนี้คือ 1.0.2 (จากรอบ retrain อัตโนมัติรอบแรก 5 ต.ค. 2026)

| ไฟล์ | เนื้อหา |
|---|---|
| `cloud_seq2seq_12to18.onnx` | โมเดลในรูปแบบ ONNX |
| `cloud_seq2seq_metadata.json` | รุ่น รูปแบบข้อมูลเข้าออก และผลของรอบ retrain ล่าสุด |

retrain ด้วย `service/training/retrain_convlstm.py` จากภาพจริงที่เก็บไว้ รอบละ 50 เวลาสแกน ภาพที่ผู้ดูแลทำเครื่องหมายว่าใช้ไม่ได้จะไม่ถูกใช้
