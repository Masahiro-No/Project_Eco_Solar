# LSTM (`model/time-series`)

โมเดลพยากรณ์ GHI จากสภาพอากาศ รับข้อมูลย้อนหลัง 36 ช่อง (6 ชั่วโมง ช่องละ 10 นาที) 16 ฟีเจอร์ ทำนาย 18 ช่องถัดไป (3 ชั่วโมง) รุ่นที่อยู่ในโฟลเดอร์ตอนเขียนเอกสารนี้คือ 1.1.1 รุ่นปัจจุบันดูได้ที่ `model_meta.json`

| ไฟล์ | เนื้อหา |
|---|---|
| `solar_ghi_lstm.onnx` | โมเดลในรูปแบบ ONNX ที่ `inference-worker` รัน |
| `feature_scaler.joblib` | ตัวปรับสเกลของฟีเจอร์ 16 ตัว ต้องเป็นชุดเดียวกับตอนเทรน |
| `target_scaler.joblib` | ตัวปรับสเกลของ GHI ใช้แปลงผลกลับเป็น W/m² |
| `model_meta.json` | รุ่น ความยาวข้อมูลย้อนหลัง รายชื่อฟีเจอร์ ค่าความคลาดเคลื่อนรายระยะ (ใช้วาดแถบความไม่แน่นอน) และประวัติ retrain |

ทั้งสี่ไฟล์ต้องมาจากการเทรนรอบเดียวกัน เทรนตั้งต้นด้วย `service/training/train.py` และ retrain ด้วย `service/training/retrain_timeseries.py`
